# Technical Setup

## Requirements

- Python 3
- PostgreSQL
- Microsoft Excel
- Power BI Desktop (Windows)

## Python environment

From the repository root:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r unidad_11_preparacion_profesional/portfolio/requirements.txt
```

## Project workflow

1. Prepare the source datasets.
2. Execute the corresponding PostgreSQL scripts.
3. Run the Python analysis and automation scripts.
4. Review the Excel reports.
5. Open the Power BI dashboards and update data source paths if required.
