# Proyecto 1 - Financial Performance Workbook

## Objetivo del proyecto
Analizar el desempeño financiero y comercial de una empresa mediante sus registros históricos de ventas, ingresos, costos y utilidad bruta, identificando tendencias, productos y regiones relevantes para apoyar la toma de decisiones.

El análisis buscará determinar no solo cuánto vende la empresa, sino también cuánto beneficio bruto generan sus operaciones y qué factores podrían explicar los cambios en sus resultados.

## Indicadores clave (KPIs)

1. Ingresos totales: valor de las ventas realizadas.
2. Costos totales: costo de los productos vendidos.
3. Utilidad bruta: ingresos menos costos.
4. Margen bruto (%): utilidad bruta dividida entre ingresos, multiplicada por 100.
