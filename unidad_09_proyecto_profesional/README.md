## 1. Descripción del proyecto

Desarrollo de un análisis integral del desempeño financiero y comercial de una empresa de distribución, utilizando Excel, SQL, Python y herramientas de visualización.

El proyecto busca identificar oportunidades para mejorar la rentabilidad mediante el análisis de ventas, costos, clientes, productos, regiones y presupuestos.

Se utilizará un dataset sintético, claramente identificado como tal, diseñado para simular condiciones empresariales realistas.

## 2. Problema empresarial

La empresa presenta crecimiento comercial, pero la dirección desconoce si ese crecimiento se traduce en mayor rentabilidad.

Se requiere responder:

- ¿Qué productos y regiones generan mayor ingreso y utilidad?
- ¿Qué clientes presentan mayor rentabilidad?
- ¿Dónde se concentran los costos y las desviaciones presupuestarias?
- ¿Qué factores explican las diferencias entre crecimiento comercial y rentabilidad?
- ¿Qué decisiones permitirían mejorar los resultados?

## 3. Objetivos técnicos

1. Construir y documentar un conjunto de datos transaccionales.
2. Detectar duplicados, valores faltantes e inconsistencias.
3. Desarrollar consultas SQL para calcular indicadores financieros y comerciales.
4. Validar resultados mediante Python.
5. Construir un modelo financiero en Excel.
6. Desarrollar una visualización ejecutiva.
7. Presentar hallazgos y recomendaciones respaldadas por datos.

## 4. Indicadores principales

| Área | Indicadores |
|---|---|
| Comercial | Ingresos, unidades, ticket promedio, crecimiento |
| Rentabilidad | Costos, utilidad bruta, margen bruto |
| Clientes | Ingresos y rentabilidad por cliente |
| Productos | Volumen, ingresos, costos y margen por producto |
| Geografía | Desempeño por región |
| Presupuesto | Variaciones absolutas y porcentuales |
| Planeación | Proyecciones y escenarios |

## 5. Herramientas

- Excel: modelado financiero, presupuestos y escenarios.
- SQL: consultas, agregaciones y análisis relacional.
- Python: limpieza, validación y análisis.
- Power BI: dashboard ejecutivo, sujeto a disponibilidad técnica.
