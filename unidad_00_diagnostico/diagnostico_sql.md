# Unidad 0 - Diagnóstico práctico de SQL

**Fecha:** 7 de octubre de 2026
**Modalidad:** Evaluación diagnóstica
**Tiempo de trabajo registrado:** 5 h 12 min

## Objetivo

Identificar mis conocimientos actuales de SQL, reconocer mis fortalezas y detectar los temas que necesito reforzar antes de iniciar la formación.

## Temas evaluados

- SELECT, FROM y WHERE
- Operadores de comparación
- AND y OR
- ORDER BY, ASC y DESC
- AS (alias)
- Funciones SUM, COUNT y AVG
- GROUP BY

## Límite del diagnóstico

La evaluación se detuvo al llegar a JOIN. Recuerdo brevemente el concepto, pero todavía no sé aplicarlo para relacionar dos tablas.

Se decidió no continuar con la enseñanza de JOIN para conservar la diferencia entre diagnóstico y formación.## Fortalezas identificadas

- Comprendo la estructura básica de una consulta SQL.
- Puedo seleccionar columnas y aplicar filtros.
- Reconozco operadores de comparación.
- Comprendo la diferencia entre AND y OR.
- Tengo conocimientos previos de SQL y puedo razonar consultas utilizando ejemplos de ventas.

## Dificultades observadas

- Necesito reforzar la sintaxis para escribir consultas sin ayuda.
- Debo practicar la diferencia entre filtrar, ordenar y agrupar.
- Necesito consolidar el uso de funciones de agregación.
- Debo reforzar el uso de alias y agrupaciones.
- Todavía no sé construir consultas que relacionen dos tablas mediante JOIN.

## Conclusión diagnóstica

Tengo conocimientos básicos de SQL y cierta familiaridad con consultas de análisis de datos.

Mi principal oportunidad de mejora es pasar de reconocer instrucciones a construir consultas completas de manera autónoma.

JOIN queda registrado como un tema pendiente de aprendizaje.
